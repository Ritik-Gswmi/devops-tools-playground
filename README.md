# DevOps Tools Playground

A documentation-first handbook for understanding how software development connects to testing, packaging, deployment, and operations. A small Node.js service and its configuration provide optional hands-on examples.

## Start here

Read the [handbook index](docs/README.md) for the learning path, concepts, and exercises. It links to the relevant files and explains how each DevOps stage fits into the workflow.

For runnable examples, use the README in the corresponding folder:

- [Docker](docker/README.md)
- [Redis](redis/README.md)
- [GitHub Actions](.github/GITHUB_ACTIONS.md)
- [Kubernetes](kubernetes/README.md)
- [Prometheus monitoring](monitoring/README.md)

The examples are small and intended for learning. The handbook explains their limits and points out where production setups need additional security, persistence, and operational work.

If this handbook is useful, please consider giving the repository a star⭐. Contributions are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.
